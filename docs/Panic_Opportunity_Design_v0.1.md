# Panic / Opportunity 설계 v0.1

> 템플턴S — 공황 구간 관찰 · 가치 기준 검토 순위  
> 작성: 2026-09-01  
> 원칙: 2~3일 관찰 후 확정 · 급매수 권유 없음 · 프로그램 계산 + AI 해석

## 1. 목표

시장이 크게 빠질 때:

1. **공황에 가까운 구간인지**를 성급하지 않게 가늠하고  
2. **가치·안전마진 기준**으로 관심 종목 **검토 순위**를 보여 준다.

자동매수·“지금 사라” 단정은 하지 않는다.

## 2. 핵심 원칙

| 원칙 | 내용 |
|------|------|
| 멀티데이 | 하루 급락만으로 공포 **확정**하지 않는다 |
| 주시 → 확정 | 1일 주시 후 2~3일 조건으로 구간 진입 |
| 급하지 않음 | 가치 매수는 서두를 필요 없음 → UI 문구 고정 |
| 계산 vs 해석 | 모드·순위는 규칙, AI는 문장만 |
| 가격 ≠ 가치 | 낙폭만으로 1순위 올리지 않음 |

## 3. 시장 모드

| 모드 | 코드 | 의미 |
|------|------|------|
| 정상 | `normal` | 일상 등락 |
| 주시 | `watch` | 강한 하루·확산 조짐 → 2~3일 관찰 |
| 공포 구간 | `panic_zone` | 2~3일 조건 충족 → 기회 탐색 패널 |
| 혼조/개별 | (종목 단위) | 시장과 무관한 개별 악재 |

### 3.1 임계값 초안 (벤치마크 = KODEX 200)

**주시 (Watch)** — 하나면 충족  
- 당일 벤치마크 ≤ **-2.0%**  
- 또는 벤치 ≤ **-1.5%** 이고 관심종목 하락 비율 ≥ **2/3**

**공포 구간 (Confirm)** — 아래 중 하나 + 확산  
- **3거래일 누적** ≤ **-4.5%**  
- 또는 **2거래일 누적** ≤ **-5.5%**  
- 그리고 가능하면 관심종목 하락 비중 높게 유지  

**극단 참고 (문구 강화만)**  
- 당일 ≤ **-5%** 또는 2일 ≤ **-8%**

근거: 코스피 역사적 하루 -8%~-12%는 이미 폭락 한가운데;  
2일 -6%는 상위 극단 근처; 하루 -2%는 “강한 날” 수준.

## 4. 종목 분류

| 유형 | 코드 | 대략 조건 |
|------|------|-----------|
| 공황형 후보 | `panic_like` | 시장 급락 동행 + 중요 악재 공시 없음 |
| 악재형 의심 | `adverse` | critical/high 악재 공시 또는 시장 대비 과도한 단독 급락 |
| 보류 | `hold` | 데이터 부족·중립 |
| 해당 없음 | `none` | 정상 모드 |

## 5. Opportunity Rank (위기 시 검토 순위)

Score와 **별도**. 공포 구간(또는 주시)에서만 테이블 강조.

가중치 초안 (합 1.0):

| 항목 | 비중 | 방향 |
|------|------|------|
| Value 구성요소 | 0.30 | 높을수록 유리 |
| Price(고점대비 매력) | 0.20 | 높을수록 유리 |
| 품질(Quality) | 0.15 | 높을수록 유리 |
| 낙폭(고점/단기) | 0.15 | 적절히 맞은 쪽 가점 (과한 단독 급락은 감점) |
| 리스크 | 0.10 | 높으면 감점 |
| 분류 보정 | 0.10 | panic_like +, adverse −− |

ETF는 기업 가치 프레임이 약해 **개별주 우선**, ETF는 순위 하단 또는 참고.

## 6. UI

- 상단: 시장 모드 배지 + 한 줄 근거  
- 주시: “2~3일 관찰 중 · 급매수 아님”  
- 공포 구간: **가치 기준 검토 순위** 테이블 (expanded)  
- 카드 태그: 공황형/악재형  
- 문구: **분할매수 검토 후보** (실행 지시 아님)

## 7. 로그

`decision_log`에 `market_regime`, `panic_type`, `opportunity_rank`, `opportunity_score` 저장 (사후 검증용).

## 9. 하지 않을 것

- 자동주문  
- “바닥 확정” 단언  
- 하루 급락만으로 공포 확정  
- 뉴스 감성만으로 순위 결정
