# Phase 6 — 판단 기록 사후 검증 v0.1

> 템플턴S · 기록된 의견·Score에 대해 이후 수익률로 점검  
> 작성: 2026-09-01  
> 원칙: 프로그램 계산 · 자동매수 없음 · 가격≠가치

## 1. 목표

1. `data/decisions.jsonl`에 쌓인 판단 시점 **가격** 대비  
   - **약 1주**(5거래일)  
   - **약 1개월**(20거래일)  
   수익률을 계산해 붙인다.
2. **의견별** 평균 수익률·히트율을 요약해, 규칙·Score가 실제로 도움이 됐는지 숫자로 본다.
3. 이후 **과거 폭락 시뮬레이션**(Step 6)의 공통 엔진으로 재사용한다.

AI 해석·매수 권유는 하지 않는다. 숫자와 표만 제공한다.

## 2. 정의

| 항목 | 정의 |
|------|------|
| 기준 가격 | 판단 기록 시점의 `price` (당일 조회가) |
| 1주 수익 | 기준일 이후 **5거래일** 종가 / 기준가 − 1 |
| 1개월 수익 | 기준일 이후 **20거래일** 종가 / 기준가 − 1 |
| 대기 | 아직 해당 거래일이 지나지 않아 종가 없음 |
| 히트 (긍정 의견) | 의견이 `분할매수 관심`·`적극적 관심`이고 수익률 **> 0** |
| 히트 (부정 의견) | 의견이 `매수 회피`이고 수익률 **< 0** (회피가 맞음) |
| 중립 | `관망`·`보유/관찰` → 히트율 분모에서 제외 |

히트 정의는 v0.1 단순 규칙이다, 나중에 벤치마크 대비·리스크 조정으로 확장 가능.

## 3. 데이터 흐름

```
decisions.jsonl
    → recent_decisions()
    → 종목별 get_daily_bars()  (KIS 일봉)
    → attach_forward_returns()
    → summarize_by_opinion()
    → UI 테이블 + 요약 카드
```

- 일봉 소스: `KISClient.get_daily_bars` (date + close, 최신→과거)
- 로그가 없거나 기간이 안 지난 건 `waiting` / `—` 표시

## 4. UI

- 기존 **최근 판단 기록** 테이블 유지
- 그 아래 **사후 검증** 섹션
  - 의견별 요약 (건수, 1주/1개월 평균, 히트율)
  - 개별 기록 + 1주·1개월 수익 컬럼
- 캡션에 “자동매수 없음 · 검증은 사후 참고용” 명시
